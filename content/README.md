# Prixline content (imported from prixline.blog)

Single source of truth: the WordPress site of Luis. Nothing here is hand-authored
yet; everything is generated by the scripts in `../../scripts/`.

| Directory | Collection | Producer | Expected volume |
| ---| --- | --- | --- |
| `courses/` | one file per course | `scripts/extract-courses.ts` | 302 |
| `posts/` | one file per article | `scripts/import-posts.ts` | 813 |
| `pages/` | static pages (practicas, redes, contacto, opiniones) | `scripts/import-pages.ts` | 4 |
| `settings/` | site settings: tagline, social channels, live channel | `scripts/import-settings.ts` | 1 |

## Provenance rules

- Never edit generated files by hand: rerun the producer script instead.
- Every file carries `sourceUrl` frontmatter pointing back to prixline.blog.
- Post categories are mapped through `scripts/category-map.ts` (the origin
  taxonomy is dirty: duplicates, numeric junk, hashtags).
- Fixes to source content happen in WordPress, then get re-imported.

## Regeneration

```bash
pnpm pipeline:courses   # content/courses/**   (live: fetches origin)
pnpm pipeline:posts     # content/posts/**     (live: fetches origin)
pnpm pipeline:pages     # content/pages/**     (live: fetches origin)
pnpm pipeline:settings  # content/settings/**  (live: fetches origin)
pnpm pipeline:fixture   # run every producer offline against fixtures
```
