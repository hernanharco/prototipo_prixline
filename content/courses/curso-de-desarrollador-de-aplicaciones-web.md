# CURSO DE DESARROLLADOR DE APLICACIONES WEB

desarrollador de aplicaciones web, informática, Internet

Este curso formará al alumno en los siguientes aspectos:
– Curso Javascript
– Introducción al Javascript y HTML
– Instrucciones condicionales
– Funciones
– Objetos intrínsecos de Javascript
– Cuadros de mensaje
– Javascript y el explorador de Internet
– Tipos de datos
– Variables en Javascript
– Operadores de Javascript
– Programación XML
– Introducción al XML
– Documento Type Definition
– Presentación de documentos XML
– Hiperenlaces en XML
– Herramientas XML
– El documento XML
– Programación Web con ASP. NET
– Introducción al desarrollo de aplicaciones Web
– Directivas de página
– Módulos y manejadores HTTP
– Seguridad bajo ASP.NET
– Requisitos de ASP.NET
– Ejecutando un ASP. Configuración de IIS
– Conceptos de la programación orientada a objetos
– ASP.NET paso a paso
