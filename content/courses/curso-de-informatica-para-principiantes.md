# CURSO DE INFORMATICA PARA PRINCIPIANTES

informática, ordenadores, Internet, principiantes

Este curso trata los siguientes temas:
– Introducción a la informática
– El arranque del ordenador
– El escritorio
– El apagado del ordenador
– El ratón
– El teclado
– El Explorador de Windows
– Carpetas y archivos
– Opción “buscar”
– Accesorios de Windows

Este curso esta creado para que el alumno se inicie en el mundo de la
informática de forma sencilla. Con este Curso Interactivo aprenderá informática
de manera rápida y sencilla. Ideal para personas mayores.
Modalidades: A distancia, OnLine.
Seis meses prorrogables de tiempo para cursarlo.
Tres oportunidades de examen de evaluación.
420 horas de duración total del Curso acreditadas en el Diploma.
Tutor personalizado para consultas por mail o por la plataforma de tutorías.
Posibilidad de ampliar el temario de forma gratuita para profundizar conocimientos.
Plataforma E-Learning interactiva de tutorías personalizada.
