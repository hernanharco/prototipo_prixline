# CURSO DE PROGRAMACIÓN con VISUAL BASIC .NET

visual basic.net, informatica, ofimatica, programacion

Este curso le capacita para realizar aplicaciones con Visual BASIC.NET, tanto para Internet
como para Windows. El curso comienza desde 0 hasta llegar a conocer el 100% del funcionamiento
del programa

– Fundamentos de programación parámetros
– Orientación a objetos
– Tipos de datos como clases
– Introducción a las aplicaciones Windows
– Formularios
– Trabajar con menús
– Barras de herramientas
– Cuadros de diálogo
– Controles básicos
– Características gráficas de .NET
– Eventos de ratón y teclado
– Aplicaciones MDI
– Excepciones
– Introducción al acceso a bases de datos
– El lenguaje SQL
– Introducción a ADO .NET
– Conjuntos de datos
– Programar el DataSet
– Objetos Command y DataReader
– Crystal Reports
Modalidades: A distancia, OnLine.
