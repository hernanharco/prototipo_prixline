# CURSO DE ORTOGRAFIA española para EXTRANJEROS

ortografía, gramática, escritura, español

Este curso contiene el siguiente temario:
– Acentuación
– Signos ortográficos
– Reglas ortográficas
– Cómo conjugar los verbos
– Construir las frases con la sintaxis correcta
– Cómo usar los sustantivos, los adjetivos, los artículos, los pronombres, los
adverbios…

El objetivo de este curso es enseñarle todas las normas ortográficas necesarias
para la correcta escritura y redacción de los diferentes textos
Modalidades: A distancia, OnLine.
Seis meses prorrogables de tiempo para cursarlo.
Tres oportunidades de examen de evaluación.
420 horas de duración total del Curso acreditadas en el Diploma.
Tutor personalizado para consultas por mail o por la plataforma de tutorías.
Posibilidad de ampliar el temario de forma gratuita para profundizar conocimientos.
Plataforma E-Learning interactiva de tutorías personalizada.
