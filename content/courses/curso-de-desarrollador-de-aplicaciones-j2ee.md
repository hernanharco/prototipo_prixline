# CURSO DE DESARROLLADOR DE APLICACIONES J2EE

aplicaciones J2EE, desarrollador, java, informática, programación

Este curso formará al alumno en los siguientes aspectos:
– Fundamentos del lenguaje de programación Java
– Introducción a la plataforma Java
– Programación orientada a objetivos
– Preparando el entorno- Clases abstractas e interfaces
– Excepciones
– Paquetes en Java
– Clase System. Canales de entrada y salida estándar
– Elementos básicos
– Cadenas y Arrays
– Estructuras de control de flujo
– Objetos. Creación, uso y eliminación
– Clases, herencia y polimorfismo
– Programación con JSP.
– Instalación y ejecución de páginas JSP
– Sintaxis de los elementos JSP
– Desarrollo y utilización de componentes JSP
– Introducción a la tecnología JSP
– Páginas y componentes JSP
– Preparación del entorno de ejecución
Modalidades: A distancia, OnLine.
Seis meses prorrogables de tiempo para cursarlo.
Tres oportunidades de examen de evaluación.
