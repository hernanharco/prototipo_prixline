# CURSO DE VALENCIANO (3 NIVELES)

Este curso de valenciano permitirá al alumno aprender de una manera sencilla y
amena, dedicándole tan sólo unos minutos cada día, suficiente para ir
progresando paulatinamente y llegar a alcanzar un sólido conocimiento de esta
lengua.
Objetivos: Aprender un rico y variado vocabulario, que le permitirá mantener
conversaciones con gran fluidez.

Con este curso de valenciano podrá conocer y enriquecer un vocabulario mas
exquisito de este idioma y además podrá aprender a escribirlo sencillamente.
Modalidades: A distancia, OnLine.
Seis meses prorrogables de tiempo para cursarlo.
Tres oportunidades de examen de evaluación.
420 horas de duración total del Curso acreditadas en el Diploma.
Diploma acreditativo homologado por nuestra empresa.
Tutor personalizado para consultas por mail o por la plataforma de tutorías.
Posibilidad de ampliar el temario de forma gratuita para profundizar conocimientos.
